# Inventaire des dépôts YIRI

## Objectif

Identifier les dépôts du projet YIRI, leur rôle, leurs technologies,
leurs responsables et leurs liens avec les autres composants.

## État de cet inventaire

Liste initiale issue du cadrage de la mission.
L'existence, les URL et le rôle des dépôts restent à vérifier.
Le statut de l'analyse documentaire ne décrit pas l'état du projet.

## Méthode d'analyse

Pour chaque dépôt :

1. Confirmer son URL exacte et les droits d'accès.
2. Lire le README et examiner l'arborescence.
3. Identifier les technologies dans les fichiers de dépendances.
4. Identifier les points d'entrée et les configurations.
5. Relever les liens démontrés avec d'autres dépôts ou services.
6. Noter les fichiers sources, la branche et le commit examinés.
7. Faire confirmer les informations par le responsable.
