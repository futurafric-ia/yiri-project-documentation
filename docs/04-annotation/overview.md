# Phase 5 - Annotation

## Objectif

L'annotation consiste à enrichir les données brutes avec des informations structurées afin de permettre leur utilisation dans les systèmes d'intelligence artificielle et les traitements automatiques.

## Cas d'utilisation

L'annotation est utilisée pour :

- L'entraînement des modèles de traitement du langage naturel (NLP)
- La classification de textes
- La traduction automatique
- La reconnaissance d'entités nommées
- L'analyse sémantique
- L'évaluation des performances des modèles

## Types de données annotées

### Données textuelles

Exemples :

- Messages utilisateurs
- Documents
- Conversations
- Articles
- Traductions

### Données linguistiques

Exemples :

- Mots
- Expressions
- Phrases
- Dialectes
- Langues locales

## Types d'annotations

### Classification

Attribution d'une catégorie à une donnée.

Phrase : "Bonjour"
